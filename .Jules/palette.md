## 2026-06-08 - Standardized Right Padding for Input Overlays
**Learning:** Absolute-positioned icons or badges inside input fields often cause text overlap when the user enters long strings. Standardizing padding-right based on the overlay width ensures readability.
**Action:** Use `pr-12` for standard 24px icons and `pr-20` for text-heavy badges (like "Buscable") to maintain clear separation between user text and decorative/functional overlays.
