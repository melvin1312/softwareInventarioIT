# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-07-25 - Accessibility Foundation & Security Screen
**Learning:** Foundational accessibility features such as skip links and focus visual states are missing in the raw design prototypes of AssetTrack. Implementing "Saltar al contenido principal" skip link and "focus-visible" ring indicators establishes robust support for keyboard-only and screen reader navigation.
**Action:** Always start prototype audits by verifying skip link placement and standardized focus rings.
