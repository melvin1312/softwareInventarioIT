## 2026-08-24 - Login Password Visibility Toggle & Skip Link
**Learning:** Adding interactive password visibility toggles and skip links to static HTML prototypes without JS frameworks requires maintaining synchronized ARIA properties (`aria-pressed`, `aria-label`, `title`) and updating both `data-icon` and text content for Google Material Symbols ligatures.
**Action:** Use vanilla JS event listeners in static HTML prototypes to switch input types and update both ligature text and ARIA attributes dynamically for full keyboard and screen reader accessibility.
