## 2025-01-24 - Functional Micro-interactions in Static Prototypes
**Learning:** Adding functional micro-interactions (like a password visibility toggle) to static HTML prototypes significantly improves the perceived quality and usability of the mockup, making it feel like a real product during stakeholder reviews.
**Action:** When working on authentication or form-heavy screens, always implement basic interactive logic for visibility toggles, character counts, or inline validation to provide a more realistic user experience.
