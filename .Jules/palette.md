# Palette Journal - Critical UX/Accessibility Learnings

This journal tracks critical discoveries and UX insights gained during development.

## 2025-01-24 - Initial setup
**Learning:** This repository contains static HTML prototypes with tailwind and material icons. Accessibility, keyboard navigation, and custom action consistency are paramount.
**Action:** Always ensure keyboard support (focus ring, focus-visible, and labels) when making UX/A11y improvements, and keep changes under 50 lines.
