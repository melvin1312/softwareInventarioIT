## 2025-05-14 - Standardized Focus Styling
**Learning:** In highly dense data environments like AssetTrack, default focus indicators are often lost or insufficient. Consistent use of focus-visible rings with offsets provides high-contrast feedback that significantly improves keyboard navigation without cluttering the UI for mouse users.
**Action:** Use the Tailwind pattern `focus-visible:ring-2 focus-visible:ring-blue-600 focus-visible:ring-offset-2 focus-visible:outline-none` for all interactive elements to ensure clear keyboard navigation indicators.
